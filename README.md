The README file will contain a short summary of each task's intended function.

Task 1a: The user inputs an even number, and the program returns the sum of all even numbers up to and including that value.

Task 1b: The user enters 5 positive integers, and the program identifies how many are divisible by three, and calculates the average of those numbers. The user sees both values.

Task 2: The program reads "optometry.txt" and outputs the average age of the clients, and the percentage of the group with each eye colour, both to one decimal place.

Task 3: Two equations are given. The program inputs incrementing values until the second equation becomes more time efficient. The program then prints out the value that it occurred, and the time taken to reach that time.

Task 4: The program returns the greatest value in a given list of numbers.

Task 5: The program uses a dictionary to keep track of stock. The user can add new items, sell items, deduct quantities, display the current inventory, and handle errors.

Task 6a: The program reads "bank_accounts.txt". The user can search for their bank number using the program, and it tells them if their number is there or not.

Task 6b: The program pickles "bank_accounts.txt", and can also unpickle it.

Task 7a: The program reads "book_info.txt" and prints out its information using object orientated programming.

Task 7b: The user can add as many EBooks onto a list as they want.
